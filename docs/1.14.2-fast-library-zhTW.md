## 介面

Library 不再建立 Develop Basic／Crop 面板、編輯工具切換、Copy／Paste／Sync／Reset 編輯底列，以及底部與照片右上角 Before/After 選單；RAW ROI 實驗控制也只在 Develop 出現。Metadata／XMP、星等、旗標、Keywords、Title／Caption、EXIF 及可關閉的 Histogram 保留。已存編輯資料不刪除；Library 仍顯示相機 JPEG，Develop 保留原編輯操作。

Library／Develop 模式選擇獨立一列。搜尋、星等、旗標及重設篩選位於下一列，搜尋欄可縮放。700pt 中央區、搜尋與星等篩選啟用時，實際 hosted view fitting size 為 682×65pt，搜尋文字區寬 201.5pt，沒有超出中央區；已檢查實際渲染 PNG。這不是整個 App 任意極窄寬度的保證。

## 驗證與限制

- 四個實際 NSHostingView 測試：Inspector 原生 Develop profile 控制在 Library 不建立；Develop 保留；底列比較選單 Library 0、Develop 1（Sort 另保留）；Loupe 比較選單 Library 0、Develop 1；700pt header 尺寸。各主要變更先跑到預期 RED，再修正至 GREEN。
- Release 全套：202 tests，24 skipped，0 failures（啟用唯讀 A7RV viewport probes）。未啟用的額外相機／環境 probes 仍 skip，不代表已測全部實體相機。
- A7RV 739 配對 assets，實際 Workspace grid→single→grid、viewport 捲動、快速箭頭：主執行緒 heartbeat max 179.6ms、p95 97.9ms（前一回合 max 193.7ms）；grid→single 三次 first-ready 約 134.9／106.5／107.9ms。通過既有 <250ms stall gate；仍有約 150–200ms 卡頓，不能宣稱流暢 60fps 或本次介面變更帶來速度提升。1.14.1 前次 max 149.3ms；單次不同快取／系統狀態不能證明改善或穩定退化。

- A7RV 原檔只讀；新增 Loupe 圖片測試僅產生並清除 scratch fixture。沒有向使用者原檔寫入。
