## 改動

- 同一張照片 Fit → native JPEG 載入時，保留已顯示的相機預覽；不再先清空圖片。實際原始尺寸 JPEG 尚未完成時仍顯示 Preparing，不把 1600px 代理圖宣稱為 native 100%。
- 切換照片只讀取「新選中照片」的 memory-only camera preview；不存在時仍允許真正冷載入 placeholder。不把前一張照片放在新照片 ID 下。
- camera handoff 的小圖 LRU 上限 12 張／96MiB；原有 native cache 上限仍為 2 張／512MiB（NSCache advisory limits）。只在前景完成後向目前方向準備最多兩張 1600px 鄰圖，沒有 full-size native 鄰圖預解碼。
- native cache hit 先驗證目前檔案版本，再讀記憶體，不必進入 serial native decode queue。
- 主檔／companion 修改、刪除、重新命名等 vnode 通知會移除 ready proxy；非 UI body 的 loader 另以 fresh stat 驗證 companion 版本，decode 完成後再次驗證。這是非同步檔案事件失效，不是任意外部寫入與 compositor 之間的原子同步保證。
- 保留 1.14.2 Library 介面簡化、Develop RAW／ROI、Histogram OFF、快捷鍵、Trash 安全與模式／selection／revision／cancellation guard。不修改 RAW tone pipeline。
