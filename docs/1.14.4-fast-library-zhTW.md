# LumiBase Fast Library 1.14.4（僅本機）

## 操作修正

- Library 與 Develop 的普通左鍵操作一致：**按住暫時 100%，放開回 Fit**。短 click 不鎖定。先前 1.14.1 把 Library 解讀成單擊持續切換，是實作方的錯誤，不是使用者操作問題。
- 雙擊完成、Z、明確 zoom 按鈕保留持續 zoom 語意；按住拖曳、滾輪換圖、畫面外放開不新增持續 zoom。切換 Library / Develop 清理 held capture。
- Library RAW 原生檢視仍優先使用 scanner 配對、同資料夾同 basename 的 JPEG；只有尺寸符合來源的完整 embedded JPEG 才可替代。**不自動解 RAW、不改 Develop tone。**

## 兩段縮放的根因與修正

1. 原生 Surface 在普通短 mouseUp 後送出 count=3，Library callback 切換 `inspection.persistent`，導致放開不回 Fit。移除單擊鎖定政策，使用共同 held / double-click 路徑。
2. Camera handoff 只有 proxy bitmap：同步 selected handoff 的 fullExtent 是零，異步 `accept` 又使用 1600px proxy 尺寸。100% intent 因此先畫成 Fit 或 proxy 的像素尺度，之後才跳到來源尺度。
3. 現在 loader 的 decodeQueue 讀取 matching JPEG / source 的 metadata 與 EXIF orientation，將 oriented fullExtent 與 versioned proxy 一起存入原有 bounded memory frame。主執行緒 handoff 只查記憶體，image / geometry 原子取得；同圖與換圖都使用來源 extent / Retina backing scale。未確知 extent 時仍明示 Preparing，低解析 proxy 不冒充原生完成。
4. mounted 原生換圖測試額外抓到 grid / filmstrip 多尺寸 entry 擠掉暖 Loupe proxy。handoff LRU 僅收 1600px Loupe proxy；其他尺寸仍使用原有 thumbnail cache。**12 entries / 96MiB、native 2 entries / 512MiB、方向性兩個 neighbors 均不擴大。**
