# LumiBase 1.13.0：目前照片位置

底部原有照片數量標籤改為 `X / N photos`：

- `X` 從 1 開始，是目前作用中照片在**目前篩選後、依目前排序排列**的集合內的位置。
- `N` 是這個可見集合的照片數，不是整個資料夾的總數。
- 多選時使用目前顯示／作用中的照片（`primarySelectedAssetID`），不是選取數量，也不任意挑選 Set 的第一筆。
- 沒有作用中照片、照片已被篩選隱藏或 ID 已失效時，只顯示 `N photos`；空集合顯示 `0 photos`，不捏造第 1 張。
- 掃描中的進度訊息維持原狀。

此版本以 PR9 的 `709b7d8760c34e6984f8c794a03b254371725023` 為基礎，保留 Backspace 確認與 RAW 原生基準曝光。未混入 PhotoCraft／tone 實驗，bundle ID 維持 `com.lumibase.LumiBase.Inspection.ROI`。
