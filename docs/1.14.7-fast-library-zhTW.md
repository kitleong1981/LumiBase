## 原生 Settings

按 **⌘,**（LumiBase Fast Library → Settings），展開 **Performance / Cache**。

- **Library JPEG ROI — Experimental**：OFF（全新偏好設定預設）、前後各 1 張、前後各 2 張。使用者明確選擇後會在重啟時保留。

- 顯示快取 entries / MiB，**Clear ROI cache** 可取消尚未發布的工作並清空。
- 設定變動會使舊工作失效並立即裁減快取；仍僅有一個 utility helper。只在 Library 的原生 100% 檢視完成後產生鄰居 ROI，不在 Grid / Fit 解碼、不預存完整鄰居 native bitmap，也不是 Develop RAW ROI。

預算包含 ROI 與同張照片的低解析 fallback，**不是 App + helper RSS 上限**。短命 helper 仍需完整 JPEG 解碼，冷啟動瞬間可約 750 MB；先前 ±1 實測部分首次原生顯示改善，但暖 native hit 可能更快，記憶體可能增加。保留實驗標示與預設 OFF，不宣稱所有照片或平台加速。

保留既有 Library / Develop 工作區、按住左鍵 100%／放開 Fit、Trash 確認安全、RAW 基準、metadata / histogram 關閉時的安全性。

## Sharpness · Preview（實驗，預設 OFF）

在 **⌘, → Sharpness / Preview — Experimental** 勾選 **Show preview sharpness score**；設定會保留。照片右下角顯示數值。只分析當前已顯示的全畫面預覽，**不额外解碼 RAW、不掃全資料夾、不以 ROI 局部畫面重新評分，也不延後 first-ready publication 等分數**。

算法：固定長邊 1024 px 灰階、64×64 Laplacian variance blocks、最高 10% 平均；一個 utility worker＋一個最新 pending job，256 個 scalar cache。來源／完整 edits／policy／算法版本／view 與輸入預覽尺寸在 key；切換照片、重編輯或關閉會取消／拒絕過期 publication。

這是**相同 view／預覽品質下的相對指標**，不是對焦成功機率；Grid 低解析來源會先 resample，數值不能和 Loupe 或原 full-resolution Python 門檻直接比較。雜訊／銳化可能拉高分数，裁切也會改變分數；沒有自動 reject。

### 真實 hosted OFF / ON 三輪比較

同一组三張配對 RAW/JPEG（其中一張只在記憶體加曝光），相同 Grid→Loupe→每張 100%→返回 Fit→rapid mixed 選取 trace；先跑完整未計入 OFF/ON warmup，再交替模式，OS caches 未清除。下表是實際 SwiftUI / AppKit host publication，不是 compositor latency，也未測 FRV。

| 指標 | OFF | ON |
|---|---:|---:|
| Loupe first-ready 中位 | 18.25 ms | 19.82 ms |
| native-ready 中位 | 8.93 ms | 4.78 ms |
| 主執行緒 heartbeat 最大 | 72.60 ms | 76.23 ms |
| 每輪 process CPU 中位 | 255.08 ms | 309.08 ms |
| 每輪 peak RSS 增量中位 | 45.64 MiB | 53.83 MiB |

ON 的背景非快取 score compute wall 中位 **2.16 ms**、最大 **8.09 ms**；同 worker thread CPU 中位 **2.16 ms**、最大 **8.07 ms**；scalar cache hits 約 0.002 ms。ON/OFF 各輪都 **3 sourceLoad / 3 processedRender**（score 沒增加 RAW 載入或 render），ON 4 次新 score 計算。first-ready 中位約增加 **1.57 ms**，trace CPU 約增加 **54 ms**、RSS peak 增量約多 **8.19 MiB**。native ON 較快不能歸因為 score 加速：非 gating 計算與快取／host 排程會擾動結果；只有三輪，並非所有資料夾的性能保證。heartbeat 在 OFF 已有約 73 ms 延遲，不能把整體不順全歸因到約 2–8 ms 背景 score。
