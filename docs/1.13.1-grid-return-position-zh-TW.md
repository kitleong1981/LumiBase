# LumiBase 1.13.1：單張返回格狀檢視的位置修正

## 原因與最小修正

`WorkspaceView` 的模式分支會在離開格狀檢視時移除 `GridView`，返回時重新建立 ScrollView／LazyVGrid。原本只有 `primarySelectedAssetID` 的 `onChange` 會捲動；同一張照片返回時 ID 不變，因此新的 ScrollView 停在頂端。

- 在 LazyVGrid 的第一次非零尺寸 layout 後，以 `onGeometryChange` 加一個主執行緒輪次，讓 ScrollViewReader 完成目的地註冊，再無動畫捲到目前作用中照片。
- 每個 GridView lifetime 只恢復一次；之後使用者手動捲動或 lazy layout 更新不會反覆置中。
- 捲動前重新驗證仍在 grid 模式且 active ID 存在於目前篩選／排序集合。被篩選隱藏、失效 ID、無選取或空集合時不捏造第一張、不改選取。
- 原有方向鍵選取變更捲動保留，並同樣檢查目標可見性。
- 保留 `X / N photos`、Backspace 安全確認與原生 RAW baselineExposure 修正。沒有加入新的 100% 預覽功能；bundle ID 不變。
