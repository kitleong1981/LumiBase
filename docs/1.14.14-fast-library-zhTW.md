# LumiBase Fast Library 1.14.14

## Lightcraft 啟發之高光色相恆定、白點保護與鏡面反射去飽和

本版本針對 v1.14.13 的高光調整（Highlights）進行重大架構升級，參考現代 RAW 顯影引擎 **Lightcraft** 的設計思維，徹底修復過去拉低高光（如 Highlights = -100）時畫面暗淡發灰、雲層扁平如末日風暴、藍天褪色變髒的問題。

### 1. 鎖定白點（White Point 1.0）與中間調保護
- **問題分析**：
  - 過去在 `AdobeColorPipeline.swift` 的 1D 樣條色調曲線中，`p4Y`（輸入 1.0 的白點輸出值）錯誤地受 `hlP4 = hlFactor * 0.13` 牽引。當 Highlights 調為 -100 時，白點被硬生生壓至 0.87（221 / 255），導致整張照片喪失純白高光，天空最高亮度被鎖死在死灰區間。
  - 同時，中間調 `p2Y` 亦被拉低了近 1 檔曝光，使白天照片中的小船、海面與前景瞬間變為陰暗傍晚。
- **修復方式**：
  - **白點（Point 4）永久鎖定為 1.0**：對齊 Lightroom PV2012 與 Lightcraft 規範，高光滑桿僅調節高光肩部，絕不壓低白點（白點由 Whites 滑桿掌控）。太陽、波光反光與雲彩亮邊永遠保持純白通透。
  - **中間調（Point 2）維持 0.50 原生陽光感**：保護 $Y \le 0.55$ 的中低亮度區域，確保前景與水面明朗透亮。
  - 僅對 $0.60 \sim 0.92$ 的高光肩部區間進行平滑自然壓縮，舒展雲層階調。

### 2. 標準路徑色調曲線與飽和度保護 (`HighlightRollOffKernel`)
- **移除著色器亮度降低，完整保留原生色彩彩度**：
  - 根據實際測試與同行審查，先前在 `HighlightRollOffKernel` 額外施加的增益衰減會使標準路徑之高光區亮度雙重下壓，造成視覺飽和度偏低、畫面偏暗。
  - 移除了該 Kernel 的亮度降低計算，將高光階調壓縮純粹交由修正後的 `CIToneCurve` 處理（白點鎖定於 1.0、中間調保留 0.50）。
  - 標準路徑的 `HighlightRollOffKernel` 僅負責在極限鏡面反光處（$mx > 0.985$）平滑去飽和防彩邊，藍天與雲彩彩度 100% 豐潤保留。

### 3. Advanced RAW 實驗開關：GPU「彩度上限」（Chroma Cap）與色域對齊
- **Oklab 感知色彩空間之彩度上限（Chroma Cap）**：
  - 在 `AcceptedHighlightsKernel` 的 GPU 核心中，針對深層高光重建新增「彩度上限」防護。
  - 隨明度 $L$ 攀升至 1.0，動態收斂允許的最大彩度 $C_{\max}(L) = \min(0.28, (1.0 - L) \times 0.85)$，在保持精確色相角（$\text{atan}(b, a)$）的同時，杜絕高亮度天空被誤拉爆為霓虹怪色。
- **Lightcraft 風格之顯示色域對齊（Gamut Mapping）**：
  - 轉換回線性 RGB 後，若有任一通道溢出顯示上限（$> 1.0$），依據該像素之相對亮度平滑向亮度收斂去飽和，保證物理數值無溢出無色階斷裂。

### 4. Lightcraft 級 GPU 雙曝光 HDR 融合與保邊導向濾波微對比還原
- **雙曝光線性場景輻照度重構（`hdrBlend`）**：
  - 解決單曝光 RAW 解碼在 1.0 處硬截斷（Clip）導致雲層數據平坦喪失的物理瓶頸。
  - 在 GPU 線性空間中取 EV 0 與 EV -2（$\times 4.0$）於 $0.65 \sim 0.95$ 亮度區間平滑融合，找回感光元件高達 4.0+ 的真實高光動態範圍。
- **對數亮度快速導向濾波（Fast Guided Filter）基底／細節分離**：
  - 以 $\sigma = 0.015 \times \text{longEdge}$、$\varepsilon = 0.35$ 分解對數空間大面積照明基底層（Base Layer）與高頻微對比層（Detail Layer）。
  - 僅針對基底層依高光係數衰減（$Base' = Base - hl \times 1.7 \times w_h$），**高頻微對比細節層 100% 保持不動**，徹底保留立體雲層紋理與放射狀耶穌光（God Rays）。
- **預設全面啟用與匯出同步**：
  - 將全域與預設狀態調整為 `true`，RAW 檔案於負高光下自動啟用該演算法。
  - 在 `selectedAssets` 與 `exportPhotos` 中增加 `liveDevelopXMP` 自動合併邏輯，確保拖曳滑桿後直接按匯出時，參數 100% 即時生效。
