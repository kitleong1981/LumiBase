# LumiBase Fast Library 1.14.14

## Lightcraft 啟發之高光色相恆定、白點保護與鏡面反射去飽和

本版本針對 v1.14.13 的高光調整（Highlights）進行重大架構升級，參考現代 RAW 顯影引擎 **Lightcraft** 的設計思維，徹底修復過去拉低高光（如 Highlights = -100）時畫面暗淡發灰、雲層扁平如末日風暴、藍天褪色變髒的問題。

### 1. 鎖定白點（White Point 1.0）與中間調保護
- **問題分析**：
  - 過去在 `AdobeColorPipeline.swift` 的 1D 樣條色調曲線中，`p4Y`（輸入 1.0 的白點輸出值）錯誤地受 `hlP4 = hlFactor * 0.13` 牽引。當 Highlights 調為 -100 時，白點被硬生生壓至 0.87（221 / 255），導致整張照片喪失純白高光，天空最高亮度被鎖死在死灰區間。
  - 同時，中間調 `p2Y` 亦被拉低了近 1 檔曝光，使白天照片中的小船、海面與前景瞬間變為陰暗傍晚。
- **修復方式**：
  - **白點（Point 4）永久鎖定為 1.0**：對齊 Lightroom PV2012 與 Lightcraft 規範，高光滑桿僅調節高光肩部，絕不壓低白點（白點由 Whites 滑桿掌控）。太陽、波光反光與雲彩亮邊永遠保持純白通透。
  - **中間調（Point 2）維持 0.50 原生陽光感**：保護 $Y \le 0.55$ 的中低亮度區域，確保前景與水面明朗透亮。
  - 僅對 $0.60 \sim 0.92$ 的高光肩部區間進行平滑自然壓縮，舒展雲層階調。

### 2. 單級 GPU 著色器：HighlightRollOffKernel
- **色相恆定（Hue-Constancy）線性縮放**：
  - 過去 1D 曲線直接作用於非線性 sRGB 各通道，破壞了 $R:G:B$ 比例，導致天空藍變質偏紫青、金色夕陽變髒黃。
  - 新增 `HighlightRollOffKernel`（Metal-backed `CIColorKernel`），在亮度域中計算平滑 Hermite 肩部曲線，並對線性 RGB 實施等比例曝光縮放，保證色彩比例 100% 恆定。
- **徹底移除光暈雙重 Unsharp Mask**：
  - 移除了原先用來彌補雲層扁平感的兩道 `CIUnsharpMask`（半徑 4.0 與 32.0）及 `CIBlendWithMask` 濾鏡鏈。
  - 徹底杜絕逆光樹枝、建築輪廓交界處產生的黑白光暈（Halos），同時大幅減少 GPU 繪圖負擔。

### 3. 鏡面反射高光自然去飽和（Specular Roll-off Desaturation）
- **問題分析**：若過早或全面去飽和，高飽和度的藍天（Blue 通道高達 0.90~0.95）會被當作過曝而洗成灰色。
- **修復方式**：
  - 對齊 Lightcraft `finish.wgsl` 規範：僅在通道真正接近或超出顯示色域的極限過曝時（$mx > 0.985$），才平滑過渡收斂向中性純白。
  - 徹底釋放純淨藍天與日落金黃的濃郁飽和度，同時消除過曝光源邊緣的刺眼彩邊（螢光黃/青假色）。
  - 同步將此極限收斂保護整合至 `AcceptedHighlightsKernel` 的 Advanced RAW 模式中。
