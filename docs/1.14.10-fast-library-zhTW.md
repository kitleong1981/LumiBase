# LumiBase Fast Library 1.14.10

## 左鍵 HOLD 100% 的點擊位置

修正「剛換照片後，左鍵按住偶爾直接放大到圖片正中央，而非剛點的位置」。選取 publication 與非同步 loading task 之間，畫面可顯示新照片自己的 resident handoff preview；舊分支只設定 `held = true`，沒有從 Fit letterbox 影像座標計算 center，因此沿用預設 0.5／前一次位置。現在所有普通 native mouse-down 都先用當前所顯示照片的 Fit geometry 計算 oriented normalized source point，再開啟暫時 100%。非同步 decode 不重設 center；既有 asset／source／edit revision guards 不變。

實拍裁切測試另確定：Library cropped Fit proxy 先攜帶未裁切 holder 的 9504×6336 extent，但 native cropped output 為 5704×4436，會在 handoff 時改變尺度。現在僅修正這兩個 Fit publication 的 geometry metadata，使用既有 crop／straighten 的 integral full-output bounds，與 native crop 保持同一座標域。沒有修改 RAW/JPEG pixel-render pipeline、crop 演算法或 sharpness 公式。

靠近邊緣時仍會 clamp，避免 100% 露出黑邊：點擊像素可能不在 viewport 正中央，這是預期而非又跳到圖片正中央。影像比 viewport 小的軸仍置中。按住／放開回 Fit、Z／完成雙擊才持續、wheel 換圖、Trash sheet hold、Settings keyboard ownership、已編輯 Library 與 1.14.9 全解析度 sharpness 的規則不變；cache entries／byte budgets／selected-only RAW 排程沒有擴大。全圖 score 的 CPU／RAM／decode 成本仍見 [1.14.9 說明](1.14.9-fast-library-zhTW.md)，本版不提出新的效能保證。
